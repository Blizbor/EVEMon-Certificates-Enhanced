# EVEMon Certificates Enhanced

🇬🇧 Enhanced EVEMon combat certificates with clearer visibility of T1/T2 access, specialization and support-skill progression for weapons, drones and tank.

These three projects are designed to complement one another:

- [**EvE Modular Skillplans**](https://github.com/Blizbor/EvE-Modular-Skillplans) tells you what to train;
- [**EVEMon Pilot Progression**](https://github.com/Blizbor/EVEMon-Pilot-Progression) shows where the pilot has gaps;
- [**EVEMon Certificates Enhanced**](https://github.com/Blizbor/EVEMon-Certificates-Enhanced) improves visibility into how well the pilot is trained.

**[Continue in English](README-EN.md)** for full documentation, installation instructions and contributor material.

Installation problems, certificate errors and suggestions: [GitHub Issues](https://github.com/Blizbor/EVEMon-Certificates-Enhanced/issues).
