# EVEMon Certificates Enhanced

Enhanced EVEMon combat certificates with clearer T1/T2 access, specialization and support-skill progression for weapons, drones and tank.  
Rozszerzone certyfikaty EVEMon z czytelniejszą progresją T1/T2, specjalizacji i supportów dla broni, dronów i tanku.

**EVEMon Certificates Enhanced** adds detail to EVEMon's combat certificates. It complements the broad pilot audit from **EvE Pilot Progression**, while **EvE Modular Skillplans** provides the training modules and paths used to close identified gaps.  
**EVEMon Certificates Enhanced** zwiększa szczegółowość certyfikatów bojowych EVEMona. Uzupełnia szeroki audyt z **EvE Pilot Progression**, a **EvE Modular Skillplans** dostarcza modułów i ścieżek potrzebnych do zamykania wykrytych luk.
