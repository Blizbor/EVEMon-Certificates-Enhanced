# Quick start

1. Install EVEMon from https://github.com/mgoeppner/evemon/releases.
2. Start it once and **install all datafile/SDE updates**.
3. Close EVEMon.
4. Download the ZIP from Releases: https://github.com/Blizbor/EVEMon-Certificates-Enhanced/releases
5. Run `Install-EVEMon-Certificates-Enhanced.ps1 -Preview`.
6. If the plan looks correct, run it again without `-Preview`.

After a later EVEMon datafile update, run the installer again.
