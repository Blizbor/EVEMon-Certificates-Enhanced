# Współpraca z EVEMon Pilot Progression

**EVEMon Pilot Progression** (https://github.com/Blizbor/EVEMon-Pilot-Progression) odpowiada na pytanie „jak szeroko rozwinięty jest pilot?”. **EVEMon Certificates Enhanced** odpowiada dokładniej „jak głęboko ma wyszkolony ten konkretny system?”. Razem dają szybki audyt zarówno nowego, jak i 50M+ SP pilota.
