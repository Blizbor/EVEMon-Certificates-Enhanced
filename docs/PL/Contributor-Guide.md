# Zasady dla kontrybutorów

Certyfikat ma odpowiadać na konkretne pytanie o możliwości pilota. Nie mieszaj dostępu do T2 z przypadkowymi supportami, jeśli utrudnia to interpretację. BASIC powinien pokazywać minimalne sensowne wejście. Każdy kolejny poziom musi mieć jasne znaczenie. Weryfikuj aktualne nazwy skilli i zależności w bieżących datafiles EVEMona. Dyskusje prowadź przez GitHub Issues.
