# Co zmieniamy

Celem jest większy kontrast między „dopiero odblokowane”, „T2 dostępne”, „kompetentne”, „mocne” i „specjalistyczne”. Supporty są rozdzielane od samego dostępu do broni tam, gdzie poprawia to czytelność. Projekt modyfikuje tylko certyfikaty i nie patchuje `eve-skills` ani `eve-masteries`.
