# Szybki start

1. Zainstaluj EVEMon z https://github.com/mgoeppner/evemon/releases.
2. Uruchom go raz i **zainstaluj wszystkie aktualizacje datafiles/SDE**.
3. Zamknij EVEMon.
4. Pobierz ZIP z Releases: https://github.com/Blizbor/EVEMon-Certificates-Enhanced/releases
5. Uruchom `Install-EVEMon-Certificates-Enhanced.ps1 -Preview`.
6. Jeżeli plan wygląda poprawnie, uruchom bez `-Preview`.

Po późniejszej aktualizacji datafiles EVEMona uruchom instalator ponownie.
