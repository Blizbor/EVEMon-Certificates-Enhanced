EVEMon Certificates Enhanced - EVEMon package
Author: Gazzine TunakTun

IMPORTANT - FIRST USE
1. Install EVEMon from: https://github.com/mgoeppner/evemon/releases
2. Start EVEMon once BEFORE installing this package.
3. In the EVEMon datafile/SDE update screen, install all offered datafile updates.
4. Close EVEMon completely.
5. Optional preview:
     Set-ExecutionPolicy -Scope Process Bypass
     .\Install-EVEMon-Certificates-Enhanced.ps1 -Preview
6. Install:
     .\Install-EVEMon-Certificates-Enhanced.ps1
7. Start EVEMon and open Certificate Browser.

After EVEMon installs newer datafiles, enhanced definitions can be replaced.
Close EVEMon and run this installer again.

Uninstall:
     .\Uninstall-EVEMon-Certificates-Enhanced.ps1
